# 怪獣データ追加コマンド

引数で指定したウルトラシリーズの怪獣データを収集・検証し、`data/kaiju.json` に追加してコミットする。

**引数**: $ARGUMENTS（例: `ウルトラマンゼット`）

## エージェントへの指示

以下のプロンプトで Agent ツールを1回だけ起動する（調査と検証を同時に行い、2回に分けない）:

---

**エージェントプロンプト（そのまま使う）:**

```
$ARGUMENTS の全話登場怪獣・宇宙人を以下の手順で収集・検証し、JSONのみ出力せよ。説明文・表・ナレーション・サマリーは一切不要。

【手順】
1. https://ja.wikipedia.org/wiki/$ARGUMENTS を取得して全話リストと登場怪獣を把握する
2. 各怪獣について「公式別名（type）」を確認する（Wikipediaの個別ページ or 公式サイト m-78.jp を参照）
3. typeが曖昧な場合は検索して確定させる
4. 全件をJSONで出力する

【出力ルール】
- JSONのみ。前置き・後置き・表・コメント一切禁止
- 配列形式で全件を1つのJSONに含める

【フィールド仕様】
- name: 怪獣名（正式表記）
- type: 公式別名（例「熔鉄怪獣」「暗黒星人」。「宇宙人」「怪獣」等の汎用語は使わない）
- episode: 登場話（例「第1話」「第3・4話」。複数話は「・」区切り）
- episode_name: 初登場回のタイトルのみ
- origin: 出身地・出現場所
- height: 身長（例「50 m」「測定不能」）
- weight: 体重（例「2万5千 t」「測定不能」）
- desc: 1〜2文の説明（特徴・必殺技・役割）
- tc: 敵キャラは"r"、友好的・中立は""
- tags: typeと同じ値

【出力例】
[{"name":"デマーガ","type":"熔鉄怪獣","episode":"第1話","episode_name":"星空の声","origin":"梅沢市付近","height":"50 m","weight":"5万5千 t","desc":"体の79%が熔鉄で構成された怪獣。口から熔鉄熱線を放射する。","tc":"r","tags":"熔鉄怪獣"}]
```

---

## エージェント完了後の作業

1. エージェントのJSON出力を `/tmp/kaiju_new.json` に保存
2. `python3 tools/add_series.py ウルトラマン〇〇 /tmp/kaiju_new.json` を実行
3. `git add data/kaiju.json && git commit && git push`
