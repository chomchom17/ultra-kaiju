# マルチエージェント運用フロー

## 役割分担

| 担当 | 役割 |
|------|------|
| オーナー（masaomi） | 改善インプット提供・各フェーズのレビュー/承認・実装後確認 |
| 企画エージェント | 改善インプットを企画書に落とす |
| 仕様エージェント | 承認済み企画書から技術仕様書を作成 |
| 実装エージェント | 承認済み仕様書に従ってコードを実装・commit・push |

---

## フロー

```
オーナー → 改善インプット提供
    ↓
[企画エージェント] docs/planning/PLAN-NNN.md 作成
    ↓
オーナー → 企画レビュー・承認（またはフィードバック）
    ↓
[仕様エージェント] docs/specs/SPEC-NNN.md 作成
    ↓
オーナー → 仕様レビュー・承認（またはフィードバック）
    ↓
[実装エージェント] コード実装・commit・push
    ↓
オーナー → 動作確認・フィードバック
```

---

## エージェント呼び出し方

### 企画フェーズ

```
企画エージェントとして動いてください。CLAUDE.md を読んでプロジェクトを把握した上で、
以下の改善インプットから企画書を作成し docs/planning/PLAN-NNN.md に保存してください。
NNN は既存ファイルの連番の次の番号にしてください。

【改善インプット】
（ここにオーナーのアイデアを記載）
```

### 仕様フェーズ

```
仕様エージェントとして動いてください。CLAUDE.md とコードベースを読んで、
以下の承認済み企画書に基づく技術仕様書を docs/specs/SPEC-NNN.md に作成してください。
NNN は企画書の番号に合わせてください。

【承認済み企画書】
docs/planning/PLAN-NNN.md
```

### 実装フェーズ

```
実装エージェントとして動いてください。CLAUDE.md・コードベース・以下の仕様書を読んで、
仕様通りに実装してください。完了後は commit・push まで行ってください。

【承認済み仕様書】
docs/specs/SPEC-NNN.md
```

  -
