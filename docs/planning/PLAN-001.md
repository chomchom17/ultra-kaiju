# PLAN-001: 検索結果ページの独立

## 概要

現在 `index.html` は検索フォームと検索結果が同一ページ内に共存している。
検索結果を専用ページ（`search_result.html`）に分離し、URLで結果を共有できるようにする。

## ユーザー価値

- **URL共有**: 「ウルトラセブンの怪獣一覧」「第1話の怪獣」など特定条件の結果をURLで共有できる
- **ブラウザ履歴**: 検索→詳細→戻るが自然に機能する
- **トップページの整理**: index.html が検索フォームのみとなりすっきりする
- **SEO・リンク可能性**: 将来的に検索結果ページへの直接リンクが貼れる

## スコープ

**やること:**
- `search_result.html` を新規作成
- 検索条件をURLクエリパラメータで受け渡し（`?name=ゴモラ&series=ウルトラセブン&ep=1`）
- index.html の検索ボタン押下時に `search_result.html` へ遷移
- 検索結果ページに「← 検索に戻る」リンクを設置
- 既存の怪獣詳細表示（モーダル）は検索結果ページにも引き継ぐ
- デザインは index.html と統一（同じCSS・スタイル）

**やらないこと:**
- 怪獣詳細の専用ページ化（モーダルのまま）
- index.html 上のインライン結果表示エリアを削除（検索ボタンは常に search_result.html へ遷移）
- ページネーション実装

## 優先度

高

## 備考

- クエリパラメータはエンコード済みの日本語文字列を使用（`encodeURIComponent`）
- `search_result.html` はデータを `data/kaiju.json` から直接フェッチして処理
- 既存の `fetchFromDB` / `renderGrid` のロジックをそのまま流用できる
