# PLAN-003: トップページ ウルトラシリーズ最新ニュース欄

## 概要

トップページの検索フォームとシリーズグリッドの間に、
ウルトラシリーズ関連の最新情報をピックして外部リンクで表示するニュース欄を設置する。

## 挿入位置

```
[検索フォーム]
────────────────── ← ここ
最新情報
・ニュースリスト（3〜5件）
──────────────────
シリーズから探す
[シリーズグリッド]
```

---

## ニュース取得方法：選択肢と比較

### 方法A：data/news.json による手動管理（推奨）

管理者が `data/news.json` を編集して git push するだけで更新される。

```json
[
  {
    "date": "2026-06-15",
    "title": "ウルトラマンブレーザー Blu-ray BOX 発売決定",
    "url": "https://...",
    "source": "円谷プロ公式"
  }
]
```

| 項目 | 評価 |
|------|------|
| 信頼性 | ★★★★★（自分でコントロール） |
| 自動更新 | なし（手動） |
| CORS問題 | なし（同一サーバー） |
| 技術難易度 | 最小 |
| コスト | 無料 |
| 情報の質 | ★★★★★（厳選可能） |

**メリット:** 情報の質・タイミングを完全にコントロールできる。誤情報リスクなし。  
**デメリット:** 更新は手動。忘れると古い情報が残る。

---

### 方法B：Supabaseの news テーブル管理

既存の Supabase（cbxipgqfhbsmgmatherr.supabase.co）に `news` テーブルを追加。
管理画面からニュースを登録・削除でき、anon key で取得可能。

| 項目 | 評価 |
|------|------|
| 信頼性 | ★★★★ |
| 自動更新 | なし（Supabase UI で手動登録） |
| CORS問題 | なし（anon key 対応済み） |
| 技術難易度 | 中（テーブル作成・SQL が必要） |
| コスト | 無料枠内 |
| 情報の質 | ★★★★★（厳選可能） |

**メリット:** ブラウザからSupabase管理画面で更新できる（gitなし）。  
**デメリット:** テーブル作成が必要。方法Aより手間が増える。

---

### 方法C：YouTube Data API v3（円谷プロ公式チャンネル）

円谷プロ公式YouTubeの最新動画をニュースとして自動表示。  
Google の CORS 対応 API のためクライアントサイドから直接呼べる。

| 項目 | 評価 |
|------|------|
| 信頼性 | ★★★★ |
| 自動更新 | ★★★★★（完全自動） |
| CORS問題 | なし（Google API 対応済み） |
| 技術難易度 | 中（APIキー取得・設定が必要） |
| コスト | 無料（1日10,000ユニット枠内） |
| 情報の質 | ★★★（動画のみ。テキストニュースは含まない） |

**メリット:** 完全自動。円谷公式の最新情報が常に反映される。  
**デメリット:** APIキーを HTML に埋め込む必要がある（Referrer制限で対策可）。  
動画コンテンツに限定されるため、イベント・グッズ情報は拾えない。

---

### 方法D：CORS プロキシ経由で RSS 取得

allorigins.win 等のプロキシ経由でニュースサイトのRSS（アニメイト、ナタリー等）を取得。

| 項目 | 評価 |
|------|------|
| 信頼性 | ★★（外部サービス依存） |
| 自動更新 | ★★★★★（完全自動） |
| CORS問題 | プロキシが解決 |
| 技術難易度 | 中 |
| コスト | 無料 |
| 情報の質 | ★★★（ノイズが多い） |

**メリット:** 自動更新。ニュースサイトの記事が入る。  
**デメリット:** 外部プロキシが落ちると機能しない。ノイズ記事が混入しやすい。

---

## 推奨：方法A（手動JSON）＋ 将来的にB/Cへ移行

**理由:**
- ファンサイトとして情報の質・正確性を最優先したい
- 誤情報・無関係な記事を載せるリスクをゼロにできる
- 実装がシンプルで即日対応可能
- `data/news.json` を git で管理するため更新履歴も残る
- 将来的にSupabase管理に移行したくなったら切り替えやすい

## デザイン案

既存の和風スタイルに合わせた **コンパクトなリスト形式**。

```
┌─────────────────────────────────────┐
│ 最新情報                 [更新: 6/15] │  ← 薄いベージュ背景
├─────────────────────────────────────┤
│ 2026.06.15  ウルトラマンブレーザーBD... →  │
│ 2026.06.10  新シリーズ制作発表           →  │
│ 2026.06.01  ウルトラマン展 大阪会場...    →  │
└─────────────────────────────────────┘
```

- 日付: 小さく左揃え（Noto Sans JP、グレー）
- タイトル: 1行で省略（overflow: ellipsis）、外部リンク別タブ
- 右端に `→` または出典バッジ（「円谷公式」など）
- 枠は既存の `.search-block` と同系統のボーダー
- 件数: 3〜5件（多すぎず、少なすぎず）
